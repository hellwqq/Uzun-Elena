# Практическое задание №1. Вариант 24

## Этап 1. Эмулятор командной строки

### Цель работы

Разработать простую программу, которая имитирует работу командной строки UNIX-подобной операционной системы.

### Реализованные возможности

1. Приглашение командной строки с именем пользователя и компьютера.
2. Разбор введённой команды и её аргументов.
3. Обработка аргументов, заключённых в кавычки.
4. Команды-заглушки `ls` и `cd`, выводящие название команды и аргументы.
5. Команда `exit` для завершения программы.
6. Обработка неизвестных команд и неправильных кавычек.

### Используемые технологии

- Язык программирования: Python.
- Модуль `getpass` — получение имени пользователя.
- Модуль `socket` — получение имени компьютера.
- Модуль `shlex` — разбор команд и аргументов.

### Запуск программы

В терминале необходимо выполнить команду:

```bash
python main.py
```

### Примеры проверки

| Ввод | Ожидаемый результат |
|---|---|
| `ls test.txt` | Вывод команды `ls` и аргумента `test.txt` |
| `cd documents` | Вывод команды `cd` и аргумента `documents` |
| `ls "my folder"` | Аргумент `my folder` обрабатывается целиком |
| `hello` | Сообщение об неизвестной команде |
| `exit` | Завершение программы |

### Вывод

В ходе работы создана первая версия эмулятора командной строки. Реализованы ввод команд, разбор аргументов, обработка кавычек и ошибок, а также завершение программы.
