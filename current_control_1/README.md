# Эмулятор оболочки (вариант 24, этапы 1–3)

Консольный эмулятор UNIX-подобной командной строки на Python 3.9+
(только стандартная библиотека). VFS загружается из ZIP-архива и
хранится целиком в памяти.

## Настройки

| Параметр        | Описание                                            |
|-----------------|-----------------------------------------------------|
| `--vfs PATH`    | путь к ZIP-архиву с VFS; без него VFS пуста         |
| `--script PATH` | путь к стартовому скрипту с командами эмулятора     |

При запуске все параметры выводятся строками `[debug]   ключ=значение`.
Недоступный архив или скрипт: сообщение в stderr и код возврата 1.

## Приглашение и парсер

Приглашение строится из данных ОС: `имя_пользователя@имя_хоста:~$`.
Парсер понимает двойные и одинарные кавычки (`ls "my docs"`), экранирование
`\`, пустые аргументы и комментарии `#`. Незакрытые кавычки дают
`syntax error`, эмулятор продолжает работу.

## Команды

| Команда | Описание |
|---------|----------|
| `ls`, `cd` | заглушки: печатают своё имя и список аргументов |
| `exit [CODE]` | завершить работу с необязательным кодом |
| `conf-dump` | параметры эмулятора в формате `ключ=значение` |
| `vfs-info` | служебная: источник, число каталогов, файлов и байтов VFS |

## VFS

ZIP читается в память, на диск ничего не распаковывается, данные
хранятся как `bytes` (двоичные файлы поддерживаются). Права берутся из
атрибутов архива, иначе `rwxr-xr-x` для каталогов и `rw-r--r--` для
файлов. Имена с `..` внутри архива отклоняются.

## Стартовые скрипты

Команды по одной в строке; на экране видны и ввод, и вывод. Ошибочные
строки пропускаются, `#`-строки показываются как комментарии.

## Сборка и тесты

```
./run.sh --vfs examples/vfs/files.zip
python3 tools/make_vfs.py                # создать examples/vfs/*.zip
python3 -m unittest discover -v          # тесты
sh scripts/stage2_demo.sh                # параметры командной строки
sh scripts/stage3_demo.sh                # разные варианты VFS
```

## Пример

```
$ ./run.sh --vfs examples/vfs/files.zip --script examples/startup/vfs.emu
user@host:~$ vfs-info
source=examples/vfs/files.zip
directories=1
files=5
bytes=126
```
## Запуск в Windows PowerShell

Если команда `python` не работает, используй `py`.

```powershell
py tools/make_vfs.py
py -m unittest discover -v
py src/main.py --vfs examples/vfs/files.zip
py src/main.py --vfs examples/vfs/files.zip --script examples/startup/vfs.emu
```

Для запуска тестов ожидается результат `OK`.
